# DailyFlow

DailyFlow - это веб-приложение для управления повседневными задачами и повышения личной продуктивности.

## О проекте

Проект разрабатывается в рамках учебной практики и представляет собой MVP веб-приложения с клиентской логикой на JavaScript.

Приложение позволяет пользователю:
- создавать задачи;
- устанавливать дедлайны;
- управлять статусами;
- отслеживать прогресс;
- анализировать статистику выполнения задач.

## Целевая аудитория

- студенты;
- офисные сотрудники;
- фрилансеры;
- пользователи, желающие организовать свои повседневные задачи.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git / GitHub

## Планируемый функционал

- система задач;
- категории и приоритеты;
- аналитика продуктивности;
- адаптивный интерфейс;
- хранение данных в браузере.
