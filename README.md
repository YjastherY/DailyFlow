# DailyFlow

DailyFlow - учебный MVP веб-приложения для управления повседневными задачами и личной продуктивностью.

Проект выполнен как фронтенд-only приложение: все страницы написаны на HTML, CSS и JavaScript, а данные задач сохраняются в `localStorage` браузера.

## Актуальность

Повседневные учебные, рабочие и личные задачи часто теряются между заметками, мессенджерами и календарями. DailyFlow помогает собрать их в одном простом интерфейсе, быстро отмечать выполнение и видеть базовую статистику продуктивности.

## Целевая аудитория

- студенты, которым нужно планировать учебные задания и практику;
- фрилансеры и офисные сотрудники с ежедневными задачами;
- пользователи, которые хотят вести простой личный список дел без сложных сервисов.

## Функционал MVP

- добавление задач с названием, описанием, категорией, приоритетом и дедлайном;
- сохранение задач в `localStorage`;
- отметка задачи как выполненной;
- удаление задач;
- поиск по названию и описанию;
- фильтрация по статусу, категории и приоритету;
- сортировка по дедлайну, приоритету и дате создания;
- выделение задач на сегодня и просроченных задач;
- страница аналитики с прогрессом, просрочками, задачами на сегодня, фокус-оценкой и ближайшей активной задачей;
- адаптивный интерфейс для мобильных экранов.

## Технологии
