# DailyFlow

DailyFlow - учебный MVP frontend-приложения для управления проектами, задачами, дедлайнами и личной продуктивностью.

Приложение выполнено без backend, React и сборщиков. Все страницы написаны на HTML, CSS и JavaScript, а данные проектов и задач хранятся в `localStorage` браузера.

## Актуальность

Повседневные учебные, рабочие и личные задачи часто теряются между заметками, мессенджерами и календарями. DailyFlow решает эту проблему через единый интерфейс: пользователь может создать проект, разбить его на задачи, поставить дедлайны, увидеть календарь событий и оценить прогресс.

Проект полезен как учебный MVP, потому что показывает не только список задач, но и более практичную модель работы: проекты, задачи, сроки, фильтры, календарь и аналитика связаны между собой.

## Целевая аудитория

- студенты, которым нужно планировать практику, дипломный проект и учебные задания;
- фрилансеры, которым важно вести несколько проектов и дедлайнов;
- офисные сотрудники с ежедневными задачами;
- пользователи, которым нужен простой локальный планировщик без регистрации.

## Функционал MVP

- создание проектов с названием и целью;
- создание задач с названием, описанием, категорией, приоритетом и дедлайном;
- привязка задач к проектам;
- отдельное отслеживание прогресса каждого проекта;
- отметка задачи как выполненной и удаление задач;
- поиск по названию и описанию;
- фильтрация по статусу, категории, приоритету и проекту;
- сортировка по дедлайну, приоритету и дате создания;
- выделение просроченных задач и задач на сегодня;
- выбор дедлайна через календарное окно в форме задачи;
- календарь дедлайнов с задачами по дням;
- вкладки календаря для задач, праздников, японских праздников и русских праздников;
- отображение распространённых японских и российских праздников;
- карточка дня с печатающимся текстом и событиями;
- аналитика: общий прогресс, активные задачи, просрочки, задачи на сегодня, высокий приоритет, фокус-оценка, ближайшая задача и прогресс проектов;
- адаптивный интерфейс для мобильных экранов.

## Запуск

Рекомендуемый запуск через локальный сервер:

```powershell
cd C:\Users\Shizuki\DailyFlow
python -m http.server 8000
```

После этого открыть в браузере:

```text
http://localhost:8000/index.html
```

Можно открыть `index.html` напрямую через `file:///`, но для стабильной работы переходов и общего `localStorage` лучше использовать локальный сервер.
