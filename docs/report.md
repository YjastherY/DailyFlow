# Описание дипломного проекта

## Название проекта

DailyFlow - веб-приложение для управления повседневными задачами и личной продуктивностью.

## Актуальность темы

В современном ритме жизни пользователи ежедневно сталкиваются с большим количеством учебных, рабочих и личных задач. Часто информация хранится в разных местах: заметках, мессенджерах, календарях и бумажных списках. Из-за этого становится сложнее контролировать сроки, расставлять приоритеты и оценивать собственную продуктивность.

Тема разработки приложения DailyFlow является актуальной, потому что цифровой инструмент планирования помогает структурировать повседневные дела, снизить риск забытых задач и повысить личную эффективность. Для учебного проекта такая система также хорошо демонстрирует навыки проектирования интерфейса, работы с клиентской логикой и организации данных на стороне браузера.

## Целевая аудитория

Целевой аудиторией проекта являются:

- студенты, которым нужно планировать практику, домашние задания, пары и подготовку к зачётам;
- офисные сотрудники, ведущие ежедневные рабочие задачи;
- фрилансеры, которым важно контролировать дедлайны по нескольким заказам;
- пользователи, заинтересованные в простой организации личного времени.

Для выбранной аудитории важно, чтобы приложение было понятным, быстрым и не требовало сложной регистрации или настройки.

## Предполагаемые функциональные возможности

MVP приложения DailyFlow включает следующие функции:

- создание задачи с названием;
- создание проекта как совокупности нескольких задач;
- привязка задач к выбранному проекту;
- отдельное отслеживание прогресса проекта;
- добавление описания задачи;
- выбор категории задачи;
- выбор приоритета;
- указание дедлайна;
- отображение списка задач;
- отметка задачи как выполненной;
- удаление задачи;
- поиск задач по названию и описанию;
- фильтрация задач по статусу, категории, приоритету и проекту;
- сортировка задач по дедлайну, приоритету и времени создания;
- визуальное выделение задач на сегодня и просроченных задач;
- календарь дедлайнов с отображением задач по датам;
- отдельные вкладки календаря для задач, русских праздников и японских праздников;
- выбор дедлайна через календарное окно в форме задачи;
- сохранение данных в браузере с помощью `localStorage`;
- отображение статистики продуктивности, включая процент выполнения, просрочки, задачи на сегодня, фокус-оценку и ближайшую активную задачу.

В дальнейшем проект может быть расширен backend-частью, регистрацией пользователей, синхронизацией между устройствами, напоминаниями и календарём.

## Используемые технологии

На первичном этапе разработки используются:

- HTML5 для структуры страниц;
- CSS3 для визуального оформления и адаптивности;
- JavaScript для клиентской логики;
- LocalStorage для хранения задач в браузере;
- Git и GitHub для контроля версий и хранения исходного кода.

Проект не использует backend, React и сборщики, так как задача текущего этапа - реализовать понятный MVP интерфейса и базовую клиентскую логику.

## Ожидаемый результат

Ожидаемым результатом является рабочее frontend-приложение DailyFlow, состоящее из нескольких страниц: главной страницы, страницы задач, календаря и страницы аналитики. Пользователь сможет создавать проекты, привязывать к ним задачи, отмечать выполнение, быстро находить нужные задачи, выбирать дедлайны через календарь и видеть практическую статистику по дедлайнам, проектам и прогрессу.

Также результатом работы станет подготовленный набор отчётных материалов: описание темы дипломного проекта, use-case диаграмма, скриншоты реализованных страниц и ссылка на репозиторий с исходным кодом.
