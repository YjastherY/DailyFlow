# Описание дипломного проекта

## Название проекта

DailyFlow - веб-приложение для управления проектами, повседневными задачами, дедлайнами и личной продуктивностью.

## Актуальность темы

В современном ритме жизни пользователи ежедневно сталкиваются с большим количеством учебных, рабочих и личных задач. Часто информация хранится в разных местах: заметках, мессенджерах, календарях и бумажных списках. Из-за этого становится сложнее контролировать сроки, расставлять приоритеты и понимать, какие действия действительно важны.

DailyFlow актуален как инструмент личной организации, потому что объединяет проекты, задачи, дедлайны, календарь и аналитику в одном интерфейсе. Пользователь видит не только отдельный список дел, но и связь между проектами и задачами, ближайшие сроки, просрочки, праздники и общий прогресс.

Для учебного проекта такая тема также полезна, потому что позволяет показать первичные этапы проектирования и разработки: структуру многостраничного сайта, клиентскую логику, работу с `localStorage`, адаптивный интерфейс, календарное представление и подготовку отчётных материалов.

## Целевая аудитория

Целевая аудитория проекта:

- студенты, которым нужно планировать практику, дипломный проект, домашние задания и подготовку к зачётам;
- фрилансеры, которым важно вести несколько проектов и контролировать дедлайны;
- офисные сотрудники, работающие с ежедневными задачами;
- пользователи, которым нужен простой локальный планировщик без регистрации и сложных сервисов.

Для выбранной аудитории важно, чтобы приложение было понятным, быстрым и визуально приятным, но при этом давало больше пользы, чем обычный блокнот.

## Функциональные возможности MVP

В текущей версии DailyFlow реализованы следующие возможности:

- создание проекта с названием и целью;
- создание задачи с названием, описанием, категорией, приоритетом и дедлайном;
- привязка задачи к выбранному проекту;
- отдельное отображение прогресса по каждому проекту;
- сохранение проектов и задач в `localStorage`;
- отметка задачи как выполненной;
- удаление задачи;
- поиск задач по названию и описанию;
- фильтрация задач по статусу, категории, приоритету и проекту;
- сортировка задач по дедлайну, приоритету и времени создания;
- визуальное выделение просроченных задач и задач на сегодня;
- выбор дедлайна через календарное окно в форме задачи;
- календарь дедлайнов с отображением задач по дням;
- вкладки календаря: все события, задачи, праздники, японские праздники и русские праздники;
- отображение распространённых японских и российских праздников;
- карточка выбранного дня с печатающимся текстом и списком событий;
- аналитика продуктивности: общее количество задач, выполненные задачи, активные задачи, просрочки, задачи на сегодня, высокий приоритет, процент выполнения, фокус-оценка, ближайшая задача и главная категория;
- отдельный блок аналитики по проектам.

## Используемые технологии

На этапе MVP используются:

- HTML5 для структуры страниц;
- CSS3 для визуального оформления, адаптивности и анимаций;
- JavaScript для клиентской логики;
- LocalStorage для хранения проектов и задач в браузере;
- Git и GitHub для контроля версий и хранения исходного кода.

Проект намеренно не использует backend, React и сборщики, так как цель текущего этапа - реализовать рабочий frontend MVP и показать базовую клиентскую архитектуру.

## Структура интерфейса

Приложение состоит из четырёх основных страниц:

- `index.html` - главная страница с кратким описанием пользы DailyFlow;
- `tasks.html` - страница создания проектов, создания задач, фильтрации и отслеживания списка задач;
- `calendar.html` - календарь дедлайнов, задач и праздников;
- `analytics.html` - аналитика продуктивности и прогресс проектов.

## Ожидаемый результат

Ожидаемым результатом является рабочее frontend-приложение DailyFlow. Пользователь сможет создавать проекты, разбивать их на задачи, выбирать дедлайны через календарь, отмечать выполнение, отслеживать прогресс, видеть праздники и анализировать свою продуктивность.

Также результатом работы является подготовленный набор отчётных материалов:

- описание темы дипломного проекта;
- use-case диаграмма;
- скриншоты реализованных страниц;
- ссылка на репозиторий с исходным кодом.

## Перспективы развития

В дальнейшем проект можно расширить backend-частью, регистрацией пользователей, синхронизацией между устройствами, уведомлениями, повторяющимися задачами, экспортом календаря и командной работой над проектами.
