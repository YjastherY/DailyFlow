# DailyFlow database materials

Материалы для задания УП.11 по дисциплине "Технология разработки и защиты баз данных".

## СУБД

Выбрана SQLite.

## Файлы

- `schema.sql` - создание структуры БД: таблицы, PK, FK, ограничения и индексы.
- `seed.sql` - заполнение таблиц тестовыми данными.
- `queries.sql` - 5 обязательных SQL-запросов: `SELECT WHERE`, `INSERT`, `UPDATE`, `DELETE`, `SELECT JOIN`.
- `dailyflow_up11.sqlite` - созданная SQLite-база после выполнения скриптов.
- `verification_output.txt` - доказательство выполнения SQL-скриптов и запросов.

## Связанные отчётные файлы

- `../docs/up11-database-report.md` - описание структуры БД и связей.
- `../docs/er-diagram.png` - ER-диаграмма базы данных.
