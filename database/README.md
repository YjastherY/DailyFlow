# DailyFlow database materials

Материалы для задания УП.11 по дисциплине "Технология разработки и защиты баз данных".

## СУБД

Выбрана SQLite.

## Файлы

- `schema.sql` - создание структуры БД: таблицы, PK, FK, ограничения и индексы.
- `seed.sql` - заполнение таблиц тестовыми данными.
- `queries.sql` - 5 обязательных SQL-запросов: `SELECT WHERE`, `INSERT`, `UPDATE`, `DELETE`, `SELECT JOIN`.
- `dailyflow_up11.sqlite` - созданная SQLite-база после выполнения скриптов.
- `verify_up11.py` - скрипт, который пересоздаёт базу, выполняет `schema.sql`, `seed.sql`, `queries.sql` и обновляет результат проверки.
- `verification_output.txt` - доказательство выполнения SQL-скриптов и запросов.

## Как проверить выполнение

Из корня репозитория:

```powershell
python database\verify_up11.py
```

После выполнения скрипт создаёт/обновляет:

- `database/dailyflow_up11.sqlite`;
- `database/verification_output.txt`.

В сохранённом результате видно, что таблицы созданы, заполнены и обязательные запросы выполнены:

- `SELECT` с условием возвращает активные задачи высокого приоритета;
- `INSERT` добавляет новую задачу;
- `UPDATE` меняет статус задачи;
- `DELETE` удаляет тестовый комментарий;
- `SELECT JOIN` выводит задачи вместе с проектом, категорией и владельцем.
